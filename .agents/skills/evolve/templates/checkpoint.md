# Evolve checkpoint

- User goal, scope and established delivery permission.
- Actual repository/base/current revision and existing user changes.
- Completed behaviour and acceptance evidence.
- Committed/pushed/PR/merged status with verified references.
- Active work: files, current implementation and remaining verification.
- Concrete blockers and what would resolve each.
- Next eligible task and exact first useful action.
- Coverage gaps, stale evidence and material uncertainty.

Keep this compact and factual. Preserve links to deeper local evidence instead
of copying raw logs or credentials into the checkpoint.
